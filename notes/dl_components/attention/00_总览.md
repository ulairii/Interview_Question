## 一句话

Attention = **按相关性对一组 value 做加权平均**。权重由 query 与每个 key 的相似度（softmax 后）决定。

`out = softmax(q kᵀ / √dk) v`

| 角色 | 含义 | 类比 |
|---|---|---|
| Q (query) | 我要找什么 | 搜索词 |
| K (key) | 每条资料的"标签" | 文章标题 |
| V (value) | 每条资料的"内容" | 文章正文 |

## 知识地图（建议按这个顺序学/默写）

```
SDPA 与 Mask SDPA + mask      ← 唯一的核心公式，其余全是它的包装
   ├─ Self-Attention Self-Attention   Q、K、V 都来自同一序列
   ├─ Cross-Attention Cross-Attention  Q 来自 A，K/V 来自 B
   └─ Multi-Head Multi-Head       把 C 切成 H 个头并行做，再拼回
          └─ KV Cache KV Cache   自回归解码时省掉重复计算
追问与验证 追问 + 验证
```

## 四个版本一眼对比

| | Q 来自 | K、V 来自 | 注意力矩阵 | mask | 代码入口 |
|---|---|---|---|---|---|
| Self | x | x | (T, T) | causal / padding | `self_attention` |
| Cross | x | context | (T, S) | context 的 padding | `cross_attention` |
| Multi-Head | 同上，分 H 头 | 同上 | (B, H, T, S) | 同上，各头共享 | `multi_head_attention` |
| Module + cache | 同上 | 同上 | 同上 | 同上 | `MultiHeadAttention` |

## 面试写作顺序（一步步加，不要一上来写全）

1. 先写**最简 SDPA**：`softmax(q kᵀ/√dk) v`，3 行，不带 mask、不带 dropout。
2. 面试官问"decoder 怎么不看未来 / batch 长度不同怎么办"时，再加 `mask`。
3. dropout 一般口头说一句"训练时加在注意力权重上"即可，被要求才写。
4. 说明 self/cross 只是 K/V 的输入不同。
5. 被要求"多头"时再加 `view → transpose → SDPA → transpose → view → Wo`。
6. 被问推理加速时再加 KV cache。

每篇笔记里的代码都是**完整可运行**的（含 import、需要的辅助函数和自检），复制一段就能跑，不用翻别的文件。

## 符号约定

`B` batch · `T` query 长度 · `S` key/value 长度 · `C = d_model` · `H` 头数 · `dk = C/H`
