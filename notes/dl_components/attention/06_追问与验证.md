## 高频追问

| 追问 | 回答 | 详见 |
|---|---|---|
| 为什么除 √dk | 点积方差为 dk，不缩放会让 softmax 饱和、梯度消失 | [SDPA 与 Mask](01_SDPA与Mask.md) |
| softmax 沿哪个维度 | key 维（`dim=-1`），每个 query 的权重和为 1 | SDPA 与 Mask |
| `.contiguous()` | `transpose` 后内存不连续，`view` 需要连续（或用 `reshape`） | [Multi-Head](04_MultiHead.md) |
| `tril(diagonal=S-T)` | 新 query 排在 key 末尾；T=1 时整行可见 | SDPA 与 Mask |
| self 与 cross 的区别 | 只差 K/V 的输入来源；注意力矩阵 (T,T) vs (T,S) | [Self-Attention](02_SelfAttention.md) · [Cross-Attention](03_CrossAttention.md) |
| cross 要 causal mask 吗 | 不要；只屏蔽 context 的 padding | Cross-Attention |
| KV cache 省什么 | 不重算历史 K/V，每步 O(S)；代价是显存 | [KV Cache](05_KVCache.md) |
| cross 的 cache | context 固定，K/V 只算一次、复用不追加 | KV Cache |
| 复杂度 | 时间 O(T·S·d)，score 矩阵显存 O(T·S) → FlashAttention 分块避免落地 | SDPA 与 Mask |
| padding + causal 同用 | 两个 bool mask 做 `&` | SDPA 与 Mask |
| 整行全 -inf | softmax 得 NaN，需要保护 | SDPA 与 Mask |
| 位置信息 | attention 对置换等变，需要位置编码（sinusoidal / learned / RoPE） | Self-Attention |
| MQA / GQA | 多个 query 头共享 K/V 头，缩小 KV cache | Multi-Head |
| 参数量 | `4C²`（不含 bias），与头数无关 | Multi-Head |

## 常见 bug 清单

| Bug | 后果 |
|---|---|
| softmax 写成 `dim=-2` | 权重按 query 归一化，结果错误但不报错 |
| 先 softmax 再 mask | mask 位置权重不为 0 |
| `view(B,H,T,dk)` 直接重排 | 序列与通道混杂，静默错误 |
| transpose 后直接 view | `RuntimeError: view size is not compatible` |
| cross-attn 加了 causal mask | query 看不到 context 的后半部分 |
| KV cache 缓存了 x 而不是 K/V | 每步仍要重算投影，没有加速 |
| cache 沿错误的维度拼接 | shape 对不上或静默错误 |
| mask 约定记反（True=屏蔽） | 被屏蔽的位置反而可见 |

## 已验证的测试

每篇笔记里的代码块末尾都带自检，复制运行即可看到 `True`。汇总版代码另有测试文件 `code/test_ml_coding.py`，覆盖：

- SDPA 与 `F.scaled_dot_product_attention` 一致（含 causal）；
- 函数版多头 == Module 版（自注意力 + causal；交叉注意力 + padding）；
- 改动被 mask 的 padding 位置，输出不变；
- `context=x` 的交叉注意力 == 自注意力；
- 单头 `self_attention` / `cross_attention` 与 PyTorch 一致；
- 逐 token + KV cache 解码 == 整段 causal 前向；
- cross 的 cached K/V 复用结果与重算一致。

运行：`cd code && CUDA_VISIBLE_DEVICES= python test_ml_coding.py`
