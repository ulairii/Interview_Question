**Linear (MSE + L2)**：`L = 1/(2N)·||Xw+b-y||² + λ/2·||w||²` ⇒ `∂L/∂w = Xᵀ(ŷ-y)/N + λw`

**Logistic (BCE)**：因 `σ'(z)=σ(1-σ)`，链式法则后 `∂L/∂z = ŷ - y`，所以

`∂L/∂w = Xᵀ(σ(Xw+b)-y)/N + λw`，`∂L/∂b = mean(ŷ-y)`（形式与线性回归同构）。

```python
def sigmoid(z: np.ndarray) -> np.ndarray:         # 输入输出同 shape
    z = np.clip(z, -500, 500)                     # 防 exp 溢出：exp(500)≈1e217 仍在 float64 内
    return 1.0 / (1.0 + np.exp(-z))

for _ in range(epochs):
    err = sigmoid(X @ w + b) - y                  # (N,)
    w -= lr * (X.T @ err / N + reg * w)
    b -= lr * err.mean()
```

要点：bias 不做正则；多分类把 sigmoid 换 softmax，梯度仍是 `Xᵀ(P-Y)/N`；线性回归可直接 `np.linalg.solve(XᵀX+λI, Xᵀy)`，不要显式 `inv`。

### sigmoid 的稳定写法（常见坑）

- **不能照搬 softmax 的「减最大值」**：softmax 分子分母同乘常数会约掉，结果不变；sigmoid 没有这个性质，`z - max(z)` 会改变结果（单个输入恒得 0.5）。
- 朴素 `1/(1+exp(-z))` 在 `z` 是很大的负数时 `exp(-z)` 溢出（`RuntimeWarning: overflow`）。
- **面试写法：先 `np.clip(z, -500, 500)`**，一行解决，够用。
- 更严格的做法（可口述）：`z>=0` 用 `1/(1+e^{-z})`，`z<0` 用 `e^z/(1+e^z)`，两个式子数学等价，各自保证指数不溢出。
- 别在函数里 `np.round`，精度丢失；要展示再格式化。

```python
from typing import List, Optional, Tuple

import numpy as np


def sigmoid(z: np.ndarray) -> np.ndarray:
    """Overflow-safe sigmoid. z: any shape float -> same shape, values in (0, 1)."""
    z = np.clip(z, -500, 500)                                   # exp(500) ~ 1e217 still fits in float64
    return 1.0 / (1.0 + np.exp(-z))


class LogisticRegression:
    def __init__(self, lr: float = 0.1, epochs: int = 1000, reg: float = 0.0) -> None:
        self.lr, self.epochs, self.reg = lr, epochs, reg
        self.w: np.ndarray                                      # (D,), set by fit
        self.b: float = 0.0

    def fit(self, X: np.ndarray, y: np.ndarray) -> "LogisticRegression":
        """X: (N, D) float, y: (N,) in {0, 1}. Returns self."""
        N, D = X.shape
        self.w, self.b = np.zeros(D), 0.0
        for _ in range(self.epochs):
            err = sigmoid(X @ self.w + self.b) - y              # (N,)  dL/dz = p - y
            self.w -= self.lr * (X.T @ err / N + self.reg * self.w)
            self.b -= self.lr * err.mean()
        return self

    def predict_proba(self, X: np.ndarray) -> np.ndarray:
        """X: (N, D) float -> (N,) P(y=1)."""
        return sigmoid(X @ self.w + self.b)
```
