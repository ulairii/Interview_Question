# 速查：最容易写错的地方

| 位置 | 错误 | 正确 |
|---|---|---|
| 展开距离 | 不夹紧 → 负数 → sqrt NaN | `np.maximum(…, 0)` |
| `argpartition` | `kth=k`（k≥N 越界，且第 k 个不在前 k 里） | `kth=k-1` |
| K-Means | 空簇 `mean` NaN | `if m.any()` + 重采样 |
| einsum 下标 | 字符串里夹空格或重复下标（`'bc hw'`、`'nd,dd,nd->n'`） | `'bchwkl,ockl->bohw'`、`'nd,de,ne->n'` |
| 广播 | N=M 或 M=D 时不报错但全错 | 逐行注释 shape |
| `view` | transpose 后直接 view | 先 `.contiguous()` 或用 `reshape` |
| BN | running 统计写成 Parameter | `register_buffer` |
| softmax | 直接 `exp` | 先减 max；CE 用 log-softmax |
| AUC 并列 | 秩和法忽略并列 | 累积梯形法 / 平均秩 |
| NMS | `order[inds+1]` 偏移 | `order = rest[iou <= thr]` |
| Dropout | 评估时仍随机；忘记 `/(1-p)` | `self.training` 判断 |
| 标签 | `bincount` 吃负数/非整数 | 先映射成 0..C-1 |
