# 建议复习顺序

1. 第 1 天：Chamfer、KNN、K-Means、IoU/NMS（几何 + 距离，最常考的小题）
2. 第 2 天：Logistic、CE、Focal/InfoNCE、AUC（公式推导 + 稳定性）
3. 第 3 天：MHA（含 KV cache）、BN/LN/RMSNorm、Dropout、LoRA
4. 第 4 天：决策树/RF、GMM、PCA、Conv2d
5. 第 5 天：采样/Beam Search；全部默写一遍，每题限时 15–20 分钟，口述追问

每道题的自测标准：**能默写 → 能说复杂度 → 能说 3 个边界条件 → 能说一个优化**。
